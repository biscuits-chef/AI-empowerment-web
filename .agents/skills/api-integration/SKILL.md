# 接口集成

1. 以服务端代码或已批准的接口文档为准，不凭经验猜字段。
2. 明确方法、路径、状态码、请求体、响应体、认证、幂等和超时。
3. 通过应用层端口隔离传输协议；统一映射安全的用户错误。
4. 模型内容、问题详情和服务端错误一律按不可信输入处理。
5. 覆盖 2xx、400、401、403、409、429、5xx、超时和无效响应。
6. 更新 `docs/api/backend-contract.md` 并运行完整质量门禁。

禁止在浏览器存储凭证，禁止在运行配置中放置密钥。
