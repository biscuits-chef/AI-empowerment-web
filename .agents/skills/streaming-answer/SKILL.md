# 流式回答工程

1. 先写出事件序列、终态、重复事件、断线、事件缺口和取消竞态。
2. 将协议解析和界面状态分离，解析器必须支持跨网络分片和多行数据。
3. 重连携带最后事件序号；发生重放缺口时读取持久化快照。
4. 停止生成必须调用服务端取消；保持连接直到收到取消终态或明确失败。
5. 正常答案由服务端保留；重新生成追加新答案，禁止覆盖原答案。
6. 为解析、状态迁移、取消、恢复和超时编写测试。

任何不完整流不得显示为已完成答案。
