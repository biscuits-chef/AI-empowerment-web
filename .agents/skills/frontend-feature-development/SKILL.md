# 前端功能开发

1. 阅读需求、架构、接口契约和相关现有代码，列出用户路径与不变量。
2. 判断变更属于领域、应用、基础设施还是展示层，不允许页面直接访问远端接口。
3. 先定义或收紧应用端口，再实现适配器和组件；保持接口小而专一。
4. 覆盖加载、空、成功、失败、超时、重复操作和恢复状态。
5. 为纯逻辑写单元测试，为关键路径写组件测试。
6. 检查桌面、移动、键盘、深浅主题；运行 `npm run verify`。

输出必须包含变更范围、验证证据、未解决风险和回滚方法。
