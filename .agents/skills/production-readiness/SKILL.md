# 生产就绪审查

1. 逐项核对 `docs/operations/production-readiness-checklist.md`，不得代替责任人勾选待确认项。
2. 检查认证授权、数据分级、脱敏、审计、依赖和内容安全策略。
3. 检查三套 XML 配置差异、密钥隔离、只读容器、健康检查和最小权限。
4. 检查指标、告警、跟踪号、灰度、回滚、故障演练和运维手册。
5. 检查联合压测、超时预算、连接规模和浏览器兼容性证据。
6. 运行完整门禁；明确结论是通过、附条件通过或不通过。

存在关键待确认项时，不得声称已可生产上线。
